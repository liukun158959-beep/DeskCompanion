# 今日工作总结（飞书 Markdown）

读者是作者自己，任务是 10 秒看完今天还该盯什么。走 `docs +create --doc-format markdown`，只写导入能保真的语法。

## 能用的语法

标题、连贯段落、列表、引用块、表格、加粗。

禁止：emoji、高亮块、分栏、画板、Mermaid、代码块包整篇、每条日程升成标题。

## 结构（按这个顺序，不要加第四节以外的章节）

先写引用块，三行：

```
> **重点**
> 事项名（截止时间）
```

没有「最该盯的一件」时，第二行写「无」。

然后：

```
# 今日工作总结
## 日程与待办
## 进展
## 还该盯的
```

- **日程与待办**：日程和未完成待办合计多于一条，用表，列是事项、截止、状态。只有一条就一句话。没有则写「无」。
- **进展**：只写「今日对话」材料里出现过的事实，结论先行再跟一句依据。没有则写「无」。禁止把日程抄进进展冒充产出。
- **还该盯的**：最多 3 条短列表。没有则写「无」。

## 红线

- 材料没有的事不写。不知道截止就写「无截止」，不编时间、完成率、责任人。
- 标题只给上面这些章节。字段、单条事项用表或加粗标签，不升标题。
- 不要鸡汤，不要「持续推进」代替具体事项。
- 不要包一层 Markdown 代码块；直接输出正文。
