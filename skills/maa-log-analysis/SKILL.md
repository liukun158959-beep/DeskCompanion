# MAA / 桌宠日志分析

必须先调用 `read_recent_errors`。需要规程时再调用 `read_skill`，技能名 `maa-log-analysis`。没有出错记录就说没有，停止。

## 结论只能来自工具原文

禁止：网络、森空岛、模拟器、没装 MAA（原文没写就不要说）。

## 怎么读【重点】

- `maa_job daily` 且 `data 是空的`：桌宠拒写空仓，账本日期未改。
- `仓库日期是` 昨天：Daily 跳过或根本没扫到今天。
- `任务出错: 仓库识别`：MAA 扫仓失败，不等于长草整段没跑。
- `failed to match DepotAllTab` / 候选模板 0：多半还在家园，没进仓库。
- `Save image` 路径：失败截图，不要读 png。
- `任务跳过` 且空 `data`：今晚已触发过更新数据（含失败），Daily 不再 OCR。

## 回答结构

1. 一句结论（桌宠拒写 / MAA 没进仓 / Daily 跳过）。
2. 用原文里的时间和关键词作证。
3. 下一步：停手连点；回家园或停在养成材料；成功一次就停。不要让用户再整段清日常来「修识别」。
