# V10 实施计划：自然待机、动作入口与阈值吸附

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 待机 | 中性帧常驻；眨眼每 3–7 秒；笑脸每 20–40 秒偶发 |
| 自然入口 | 双击跳跃；助手成功回复播放 review |
| 发现入口 | 右键菜单增加“动作预览”，可播放原表全部动作和眨眼/笑脸 |
| 中央松手 | 保留释放位置；仅距左/右/底边 48px 内才吸附 |
| 顶部 | 不再作为吸附候选，不新增顶部动作 |

## 1. 待机状态

1. 原 idle 六帧拆为：
   - 中性循环：第 1、3、4、6 帧；
   - 眨眼一次性动作：中性 → 第 5 帧 → 中性；
   - 笑脸一次性动作：中性 → 第 2 帧 → 中性。
2. 中性帧不再每轮带出表情。
3. 眨眼和笑脸由独立时间点调度；进入 busy、拖动或一次性动作时暂停。
4. 左右 cling 不自动插入待机表情。

## 2. 动作触发

1. 单击在系统双击判定时间结束后挥手，避免双击时先闪出挥手帧。
2. 双击直接播放一次 jump。
3. 助手处理期间播放 waiting；成功返回后播放一次 review；失败播放 failed。
4. 右键“动作预览”包含待机、左右跑、挥手、跳跃、失败、等待、通用跑动、review、眨眼和笑脸。
5. 预览动作均只播放一轮；busy 时不允许预览覆盖等待状态。

## 3. 松手与吸附

1. 新增 `free` 位置状态，布局与底边使用相同的窗口内偏移。
2. 松手后计算身体到左、右、底边的绝对距离；最近距离不超过 48px 才吸附。
3. 超过阈值时保持当前位置，只把完整精灵限制在工作区内。
4. 顶边不参与计算，因此中央释放不会再瞬移到顶部。
5. `free` 与底边松手播放一次落地动作；左右边直接进入 cling。

## 4. 验收

1. 正常待机 10 秒内不连续快速笑/眨眼。
2. 眨眼间隔落在 3–7 秒，笑脸间隔落在 20–40 秒。
3. 双击、成功回复和右键预览均能触发对应动作。
4. 屏幕中央松手位置基本不变；距三条支持边缘 48px 内才吸附。
5. 无任何路径把 `edge` 设置为 `top`。

## 5. 不做

不启用自动巡游，不让桌宠自行改变位置，不新增顶部动作，不用固定慢放整条 idle 掩盖表情调度问题。
