# V41：清日常藏角色 + 状态小窗

> 2026-09-03。grill-me 已对齐：MAA 截的是游戏窗，角色挡的是真实鼠标；不采用临时点击穿透。

## 0. 问题

博士让凯尔希清日常之后，她仍置顶盖在游戏右下角。MAA 用真实鼠标点，点到角色就进不了游戏。现在凑合是自己开穿透或把她拖走。新产品必须比「先挪开角色」更快：清日常期间人看不见她挡路，但仍能核对桌宠拿到的远控状态。

## 1. 非目标

临时点击穿透；取消全局置顶；打开整页看板；改 MAA 截图/键鼠；桌宠点屏幕；把小窗做成方舟勾选页；清日常以外（仅开游戏）也藏角色。

## 2. 决策

| 项 | 结论 |
|----|------|
| 角色 | `start_daily` 一开始就 `hide_pet`。纸条不再把她拉回来 |
| 小窗 | Electron 另开普通窗（**不** `alwaysOnTop`），任务栏可见、可拖。避免再挡 MAA 点击 |
| 内容 | 只显示桌宠已有快照：动作、留言、远控是否已轮询、最近一次 `reportStatus`、当前队列 type。每秒拉一次 `maa_menu` |
| 停止 | 小窗有停止，走现有 `maa_stop` |
| 关掉小窗 | 不等于停止清日常 |
| 结束 | 成功 / 失败 / 停止后关小窗，显示角色并贴结果纸条 |

## 3. 验收

Given 角色在桌面上，When 点开始清日常，Then 角色消失，出现「清日常」小窗，游戏上的点击不再落到角色。  
Given MAA 尚未 POST `getTask`，When 看小窗，Then 远控写还没来拉任务，不是「已经在干」。  
Given MAA 已拉任务或已回报，When 看小窗，Then 能看到与桌宠 `snapshot` 一致的轮询/回报。  
Given 清日常结束或失败，When 线程收尾，Then 小窗关掉，角色回来并说出结果原文。
