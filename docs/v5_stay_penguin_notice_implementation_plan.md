# V5 实施计划：站住、拉出一下、企鹅纸条

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 换边 / 闪现 / 侧边飞 | 删除。停在用户放下的那条边 |
| 平时 | 原地 idle + 约 20–40 秒挥一次手。底边也不自己走 |
| 拉出 | 拖到侧边或顶边松手：播一次挥手，然后站住 |
| 主动搭话 | 独立企鹅对话框（不是头顶 44px 纸条，也不是对话卡） |
| 对话框 | 约 16px 字、可换行、不截断；「我知道了」才关；不自动消失 |
| 左右贴边 | 对话框贴在角色朝向屏幕内侧，整块落在工作区内 |
| 点角色 | 仍开/关对话卡。开对话卡时若纸条开着，纸条先关掉 |
| 不做 | 新画爬/飞帧、自己换边、PIL 纸条、自动超时关掉提醒 |

## 1. 现有问题对应

闪现 = `_begin_travel` 有 62% 直接改 `edge`。侧边飞 = idle/travel 用跳跃滞空帧。纸条看不清 = 分层窗上 13px 单行 7 秒。

## 2. 改法

1. 行为机只留 idle / wave / 思考 / 失败。删 traveling、airborne、换边。
2. 拖动松手 `_snap_to_edge`；若边是 left/right/top 则 `wave()`。
3. 新增 HTML 纸条模式：奶油肚皮、深灰企鹅线、黄嘴尖指向角色，「我知道了」走 bridge。
4. 删分层窗 `_draw_strip` 调用。启动推荐和 12–18 分钟模板都走纸条窗。
