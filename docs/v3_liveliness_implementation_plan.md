# V3 实施计划：小气泡开关、贴边、缩放、到点纸条

> grill-me 对齐后冻结。2026-08-14。
> 推荐项全选：一行纸条 + 240×320 对话卡；12–18 分钟模板搭话；工作区四边吸附；1x/1.5x/2x。

## 0. 决策速查表

| 决策项 | 最终选择 |
|--------|---------|
| 点咕嘎 | 对话卡开着则关，关着则开 |
| 平时 | 角色头顶一行奶油纸条，不盖身体；点纸条或点角色都展开对话卡 |
| 对话卡 | 240×320，贴在精灵侧面留缝，禁止和身体重叠 |
| 主动搭话 | 12–18 分钟一条模板（快开会 / 过期待办 / 时段问候），不调模型、不建习惯引擎 |
| 静音 | 托盘「主动搭话」开关 |
| 贴边 | 工作区四边走和坐；允许半身探出工作区。不爬其它应用窗 |
| 缩放 | 滚轮三档 1x / 1.5x / 2x，右键同样；写入 user_state.json |
| 不做 | 每日启动狂跑 Atlas 推荐、Shimeji 爬窗、无级缩放 |

## 1. 现有代码

分层窗、贴边走、三档缩放、托盘开关、模板 `nudge.py`、头顶纸条已经在树上。本波补齐缺口并修开关/挡角色。

## 2. 缺口

- 关气泡：以 WinForms `Visible` 为准，Hide 后禁止 `SWP_SHOWWINDOW` 又把它拉出来
- 对话卡按精灵身体矩形定位，不要按整块分层窗（含 padding）
- 滚轮不再要求 Ctrl
- 贴边允许探出；无日程时用时钟问候，飞书失败仍把错误写在纸条上
- 删启动时的每日 Atlas 推荐
