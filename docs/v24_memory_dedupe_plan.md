# V24 实施计划：记忆注入去重

> 2026-08-28。对话记录里同一条过期待办被模板搭话写了十几遍，再按最近 N 条灌模型。

## 0. 问题

博士雇桌宠盯今日安排。模板搭话每 12–18 分钟写一句「还没做完」进 `chat.jsonl`。人设默认喂最近 20 条，窗口里全是同一句，真正对话被挤掉。看板「对话」页也刷屏。

## 1. 非目标

不改飞书待办、不自动勾完成。不重写已有 jsonl（旧重复仍在「对话」页，清空或等窗口滑过）。不把短搭话和长今日纸条当成同一条。

## 2. 决策

| 项 | 结论 |
|----|------|
| 模板搭话 | 只出「今日」壳，不写 `chat.jsonl` |
| 落盘 | `append_chat` 若与上一条 role+正文相同，不写 |
| 注入 | `history_for_model`：按 (role, 正文) 只留最近一次，从新往旧凑满 N 条 |
| 记忆页 | 展示去重后的窗口，与模型看到的一致 |

## 3. 验收

同一句「还没做完」连续搭话：jsonl 不增长，说话前模型上下文里只有一条。记忆页条数 ≤ N 且无重复正文。跟凯尔希正常一问一答仍按条写入。
