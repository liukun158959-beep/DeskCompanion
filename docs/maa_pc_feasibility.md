# 第一版可行性：PC 客户端 + 鹰角启动器 + MAA

> 2026-08-27。实现前探路结论。不是实施计划全文。

## 能做的

- MAA **有** PC 端（实验性）：连接配置选 `PC`，`AttachWindow` 绑标题为「明日方舟」的 Win32 窗口，不是 ADB、不是安卓模拟器。
- 一键长草选项可用远控 `LinkStart-*` 与 GUI 对齐（唤醒/公招/基建/作战/信用/奖励/肉鸽/生息）。
- 桌宠可以：拉起 `MAA.exe`、按配置启动鹰角启动器或游戏 exe、用窗口标题检测游戏是否起来。

## 做不到 / 会翻车的（官方已确认）

1. **PC 的「开始唤醒」不能启动客户端。**  
   MAA 维护者：[Issue #15794](https://github.com/MaaAssistantArknights/MaaAssistantArknights/issues/15794)  
   「PC 的开始唤醒不支持启动客户端」。勾了唤醒只会多打一行失败日志。游戏窗口必须已经在。

2. **鹰角启动器没有公开的命令行「启动明日方舟」。**  
   官网只说明用启动器下载/点开始。第一版若只 `Popen` 启动器，停在启动器首页，**不会自动点开始游戏**。

3. **MAA 远控不负责开 PC 游戏。** 它只绑已有窗口。连接必须是 `PC`，不能用模拟器配置去控桌面版。

4. **PC 模式实验性**：UI 缩放 100%、分辨率 16:9；部分输入模式作战后回不去主界面；绑窗口可能要求 MAA 管理员权限。

5. **`LinkStart-*` 子任务**在部分版本远控反射失败（#16740），整段 `LinkStart` 仍可能可用。

6. **`Arknights.exe` 要求管理员提升（WinError 740）。**  
   直接 `CreateProcess` 会失败。必须 `ShellExecute`，会弹出 UAC。桌宠若不以管理员运行，每次开游戏都要点一次「是」。

## 第一版因此拆成两段，不能假装「点桌宠 = MAA 唤醒就开了 PC」

- **开游戏**：先拉起鹰角 `Launcher.exe`，再用 `ShellExecute` 启动启动器目录里的 `Arknights.exe`（PC 客户端，不是模拟器），等到该进程出现可见窗口。启动器没有 CLI「开始游戏」。
- **清日常**：窗口在了之后再让已配置为 PC 连接的 MAA 去跑勾选项。未装 MAA 则只开游戏并说明缺什么。
