# V42：清日常小窗显示 MAA 当前项

> 2026-09-03。grill-me 已对齐：远控一条 `LinkStart` 只在整段结束时报一次；心跳也只回报这条 id。实时项来自今日 `gui.log` 的 `开始任务:`。

## 0. 问题

博士藏角色看小窗时，队列只有 `LinkStart`，对不上 MAA 正在点唤醒还是作战。现在凑合是切到 MAA 窗看主界面。新产品必须比「再看一眼 MAA」更快：小窗写出 MAA 自己记下的当前项。

## 1. 非目标

改下发 `LinkStart-*`；心跳当当前项；截图进小窗；读 `asst.log` 喂模型；改扫仓合同。

## 2. 决策

| 项 | 结论 |
|----|------|
| 下发 | 仍一条 `LinkStart` |
| 当前 | `snapshot` 增加今日 `gui.log` 最新 `开始任务:` 的名称。没有则「还没开始具体项」 |
| 出错 | 该条之后若有 `任务出错:`，小窗原文带上；更早的今日出错不带 |
| 读法 | 复用 `log_inspect` 的 debug 目录和尾读，不另开通道 |

## 3. 验收

Given 今日 `gui.log` 已有 `开始任务: 理智作战`，When 看小窗，Then 当前是理智作战，不是 `LinkStart`。  
Given 还没有 `开始任务:`，When 看小窗，Then 写还没开始具体项。  
Given 该条之后有 `任务出错: 仓库识别`，When 看小窗，Then 出错原文可见。
