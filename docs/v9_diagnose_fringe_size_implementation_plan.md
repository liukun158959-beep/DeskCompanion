# V9 实施计划：自测、体型、绿边、清空

> 2026-08-14。四条问题已用离线测量定位，不靠肉眼猜。

## 0. 测出来的原因

| 现象 | 测量 |
|------|------|
| 拎起/落地变小 | 显示后 idle 身高 200px，lift 152px（0.76），land 最后一帧 165px（0.82）。格子同为 192×208，图里角色画得更小。落地压缩帧再矮是动画，但站稳帧也对不上 idle。 |
| 待机还在晃 | 正弦 bob 已删。idle 六帧 bbox 只漂 1px。真正晃的是半透明绿边每帧在爬：每帧约 90–120 个绿像素。 |
| 绿边 | 源图 idle 就有绿幕残留（如 `(0,85,0,a=3)`）。LANCZOS 缩到 192 后更明显。分层窗还吃未预乘 Alpha，低透明绿会发亮。 |
| 清空 | 气泡没有入口。 |

## 1. 做法

| 项 | 选择 |
|----|------|
| 体型 | 加载时把 lift 全条、land 全条按「站稳帧」身高拉到与 idle 一致，脚钉在 idle 脚底。落地压缩相对站稳帧仍在。 |
| 绿边/微晃 | 去绿幕残留；`UpdateLayeredWindow` 写入前预乘 Alpha。 |
| 抓点 | 放大后再从 lift 第 0 帧量后颈，写入 `Skin.drag_grip`。 |
| 清空 | 气泡标题栏「清空」：清画面 + 删 `chat.jsonl`。不改今日纸条日期。 |
| 自测 | `python -m desk_companion --diagnose`：体型比、绿边、idle 漂移、抓点不透明。我改完自己跑，不把你当测试员。 |
