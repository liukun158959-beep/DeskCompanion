# V30：右键 + 空勾选仍扫仓

> 2026-09-02。用户验收同趟再试时撞上：桌宠/看板右键没菜单；八项全关后提示「没勾、不下发」，但 MAA 的「更新数据」本应强制带上。

## 问题

1. 看板 WebView2 默认把右键菜单绑在 debug 上，非 debug 等于没有右键。
2. 桌宠右键要等 Python `maa_menu` 才弹出；点不到模型或桥慢就以为没右键。
3. `_dispatch_maa` 在 `selected` 为空时直接不下发 `LinkStart`，强制开的 UserDataUpdate 也不会跑。

## 非目标

第 9 个可关掉的「更新数据」勾选；改 pywebview 源码；整段重跑日常。

## Must

1. 看板打开系统右键菜单（复制/粘贴）。
2. 右击桌宠（角色或气泡）弹出已有菜单；桥超时也要弹出。
3. 八项全关仍下发一条 `LinkStart`（只跑更新数据）；看板和气泡方舟页一行只读说明。
