# V8 实施计划：停波动、一日一纸、后颈抓点

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 波动 | 去掉绘制层正弦上下浮动。眨眼、挥手、扒边、拎起/落地仍播精灵帧 |
| 今日纸条 | 每个自然日（东八区）只生成一次；用 Markdown：引用高亮 + 有序列表 + 表格 |
| 卡片宽度 | 最大 520，表格才放得下 |
| 拎起抓点 | 按后颈衣领，从高清 `drag-lift` 重测，不再用旧 192 格的 `(132, 52)` |

## 1. 波动

`pet.py` `_paint` 里 `sin(t) * 5` 每帧改窗口内 Y。Idle 精灵表本身不跳。删掉该位移，`bob` 恒为 0。

## 2. 今日纸条

- `user_state.json` 增加必填 `last_daily_date`（`YYYY-MM-DD` 或 `""` 表示还没写过）。
- 启动时若已是今天，不再跑模型、不弹「看一下今天的安排…」。
- 生成成功才盖日期；失败下次启动再试。
- 提示词改为：引用块 `> **重点**`、有序列表、两到三列表格。禁止再写成一段话。
- 气泡允许 `table`；引用块做成高亮。`BUBBLE_MAX_W = 520`。

旧 `chat.jsonl` 里的重复句不改写。要干净卡片就删该文件。

## 3. 高清素材与抓点

现有文件已对上 `pet.json` 的 `384×416`：

| 文件 | 实际 | 规格 |

| spritesheet.webp | 3072×3744 | 8×9×384×416 |
| cling-left/right | 1920×416 | 5 帧 |
