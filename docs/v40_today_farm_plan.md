# V40：今天刷什么（代理卡 + 日常养成）

> 2026-09-03。grill-me 按推荐冻结。Fixes #7。策略表仍以 `v25_arknights_farm_plan.md` 为准；本刀切落地范围。

## 问题

When 博士今天有理智、可能有代理卡，I want 先知道剿灭/保全还做不做、再知道日常养成关值不值得打，so I can 周玉和月增补不漏，芯片停在 5/8，碳默认不刷。

## 非目标

- 不接 `event_shop` / `event_drops`、不爬 PRTS 活动页、不接企鹅、不编打几次。
- 不做 `red_shop.want`、不做 `plan` 干员消耗。
- 不改 MAA 关卡。不后台算。不清日常顺带规划。
- 精英材料（T2/T3 主题曲）本刀不推荐关卡：没有企鹅就不能点关。

## 决策

| 项 | 选择 |
|----|------|
| 触发 | 对话「今天刷什么」必须调只读工具；看板方舟页按钮。点了才算 |
| 仓 | `require_today_inventory()`，不是今天整份失败 |
| 额度 | 今天的 `skland`。没有今天的森空岛 → 代理卡通道失败，养成仍可出 |
| 策略 | 账本没有 `strategy` 用 V25 缺省表。有则校验九个 id 排列，坏了失败 |
| 代理卡 | 缺 `常态事务代理卡` → 通道失败 + 手填样例；养成继续。不当 0 |
| 开放 | 东八区 4:00 切日。周历写死自 [PRTS 资源收集](https://prts.wiki/w/%E5%85%B3%E5%8D%A1%E4%B8%80%E8%A7%88/%E8%B5%84%E6%BA%90%E6%94%B6%E9%9B%86) |
| 芯片 | PR-A 重装/医疗，PR-B 术师/狙击，PR-C 先锋/辅助，PR-D 近卫/特种。缺任一芯片键失败，不当 0 |
| 碳 | 默认 0，不进 SK，不查碳键 |

代理卡通道：周玉未满且卡 ≥1 → 先剿灭（1 卡+理智）。卡在扣 1 之后仍 ≥2 且保全未满 → 同一条附带保全（2 卡、不耗理智）。周玉已满则只看保全。卡不够写去领日常，不拿 CA/PR 充数。

## 验收

Given 仓是今天、周玉 0/1800、代理卡 ≥1，When 问今天刷什么，Then 先剿灭，即使芯片未满。
Given 周玉已满、代理卡 ≥2、增补条或仪未满，When 提问，Then 不推荐再剿灭，建议保全，并写下个 16 日 04:00。
Given 没有代理卡键、仓是今天，When 提问，Then 代理卡通道失败样例，养成仍给出今日未达目标且开放的资源本。
Given `carbon=0`，When 今天开 SK，Then 不推荐 SK。
Given 仓不是今天，When 提问，Then 失败原文先清日常，不编关卡。
