# V4 实施计划：真贴边、上下飞、启动个性化纸条

> 对照精灵表后冻结。不新画动作。不爬其它应用窗。

## 0. 为什么不像「扒着」

1. 格子 192×208，身体大约从 x=26 画到 169。按整格探出时，先出去的是透明边，角色仍全在屏内。
2. 贴边按分层窗而不是脚/头，底边看起来像站在桌面上，不是踩任务栏。
3. 大多只在底边走，很少拐到左右/顶。
4. 个性化纸条曾改成 12–18 分钟模板，短测看不到。

上下没有爬/挂帧。跳跃滞空帧（举手离地）循环当飞，不 90 度旋转。

## 1. 决策

| 项 | 选择 |
|----|------|
| 新动作 | 不画 |
| 贴边基准 | 不透明身体并集。左右探出身体四成；脚踩任务栏上沿；头顶略探出 12px |
| 底边 | idle / 左右跑 |
| 左右、顶 | 飞（跳跃第 2–4 帧循环）。顶边纸条画在脚下 |
| 换边 | 出门时约六成改飞到另一条边；撞角约八成拐弯 |
| 个性化 | 启动立刻纸条「看一下今天的安排…」，随后 Atlas 一两句（先拉日程+待办）。失败写在纸条上 |
| 之后 | 12–18 分钟模板 |
| 静音 | 托盘「主动搭话」两条都关 |
