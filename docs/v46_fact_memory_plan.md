# V46 事实记忆

> 已对齐后冻结。窗口仍按 v16 / v24：当前线程去重后最近 N 条，思考和 token 不进窗口。不另建短期 / 工作 / 长期三套库，不做向量库，不在对话后再跑一个抽取模型。

## 问题

换一条对话之后，上一线程里说过的偏好和决定就喂不进模型。用户要模型自己判断什么该留下，并且能在主窗看见、改掉。

## 非目标

- 不把培养清单抄进事实，不算仓库缺口。
- 不记日程、仓库数量、工具结果。
- 不改「今天刷什么」和 gap 必须是今天的仓。
- 活动商店、企鹅、勾飞书待办、会前打断、练谁抽卡仍不做。

## 落笔

一份 `memory/facts.json`（目录已在 gitignore）。缺文件等于没有事实。JSON 或结构坏了，这一轮开口失败，恢复是删掉或修好该文件。

模型只有两个工具：

- `remember_fact`：一句事实，加上必须出现在这一轮用户原话里的连续片段。对不上、空句、整句重复、超过 80 字、写满 30 条，都不写入，并把原因返回。没有「已记下」就不许说已经记住。
- `forget_fact`：整句相等才删。没有「已忘掉」就不许说已经忘掉。

每日纸条没有用户原话，记不下。人在记忆页增删改，来源记成「你」；改了模型写的句子，来源改成「你」，依据原话清掉。凯尔希正在说话时，页上不能改。

下一轮开口前，事实写进系统提示，换对话也在。这一轮靠工具回执。

## 验收

- 记忆页在对话侧。上面是事实（谁写的、何时、依据原话），换对话还在。下面是当前线程会喂的 N 条，换对话不喂。N=0 写明不喂旧对话。
- 事实和窗口里的一句都能手删：先勾选，再点页面上的「删除所选」。窗口只删当前线程里相同 role+正文的行，别的线程不动。
- 原话对不上不落盘。整句相同才删除。写满必须先删一条。
- 文件坏了，页上只有失败句，没有事实行，也没有窗口行。
- 调试页 `?debug=memory` 用样本，`window.__deskDebug.memorySnapshot()` 能读出事实和窗口。调试态增删改不写文件。
