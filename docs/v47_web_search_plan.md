# V47 联网搜索

问现在的天气、新闻、网上才有的事时，模型只能靠训练里的旧知识。要它先调工具，再按工具原文说。

## 非目标

- 不另开搜索账号，不抓网页正文，不把搜索结果写进事实。
- 今日日程、今日纸条不靠联网搜索。
- 搜索接口失败时不换一家凑合。

## 做法

工具名 `web_search`。用设置里的 API 地址和 Key，请求 `{base}/tool/search`，`search_service` 用 google，`crawl_results` 为 0。返回标题、摘要和链接。失败、超时、没有链接，都把原因交回模型，不许编。

斜杠菜单里也可以点「联网搜索」，这一轮必须调用该工具。

## 验收

- 搜「杭州明天天气」时，工具原文里有天气站点的标题和链接。
- 搜索词为空、地址不是以 `/v1` 结尾、接口报错，都返回失败句。
