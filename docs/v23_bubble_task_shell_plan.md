# V23 实施计划：点击不闪、气泡跟缩放、三种任务壳

> grill-me 对齐后冻结。2026-08-28。推荐项全选：窗宽常驻修闪现；Must 三件：缩放 + 三壳 + 今日/清日常一屏看完。

## 0. 问题

点角色时 Electron 透明窗从 400 改成 720 宽（`x` 左移 320），Windows 上 `setBounds` 会闪一帧。气泡固定 320×500，滚轮只放大 Live2D，对话卡不跟。所有内容挤在同一卷聊天记录里，今日安排和清日常要上下滚，看起来累。

## 1. 非目标

不做第二块看板。不把 MAA 齿轮（关卡、吃药、基建表）搬进气泡。不改人设长文。不为长闲聊取消滚动。

## 2. 决策

| 项 | 结论 |
|----|------|
| 闪现 | 窗口永远是「气泡宽 + 角色宽」。关气泡只隐藏左侧并鼠标穿透。开关不再改窗尺寸 |
| 原点 | 存盘坐标仍是角色左上角。窗的左上角 = 角色原点 − 气泡宽 |
| 缩放 | 1.5x 为基准：角色 400×500、气泡 320。1x / 2x 按 `scale/1.5` 同时改角色画布、气泡、字号 |
| 三壳 | 页签：今日 / 方舟 / 对话。点角色默认打开「今日」 |
| 今日 | 结构化快照，不调模型。一块重点 + 最多 4 条其余。失败原文，不编造 |
| 方舟 | 状态一行 + 8 项勾选 + 打开/开始/停止。与看板、右击共用同一份勾选 |
| 对话 | 现有聊天记录，允许滚动 |
| 自动切页 | MAA 纸条切「方舟」；模板 nudge 切「今日」；用户发话切「对话」 |

## 3. 验收

1. 点角色开关气泡，角色屏幕位置不变，没有整窗闪白/跳位。
2. 滚轮 1x / 1.5x / 2x：角色和气泡一起变，气泡不还是 320px。
3. 「今日」一屏能看完重点，没有内部滚动条；飞书失败时看到恢复原文。
4. 「方舟」一屏能勾选并开始/停止，8 项都在，不用滚。
5. 跟她说话仍在「对话」，长回复可以滚。
