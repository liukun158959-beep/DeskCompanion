# V14 实施计划：漫画气泡、跑步/悬挂关键帧、脚下阴影

> grill-me 对齐后冻结。2026-08-15。

## 0. 决策

| 项 | 选择 |
|----|------|
| 圆角白底 | 气泡窗改为透明，关掉矩形阴影；形状只由 CSS 圆角卡片绘制 |
| 尾巴 | 删除深色 CSS 倒三角；改成漫画对话框菱形尖尾，填充与气泡同色 |
| 跑步 | 左/右/通用各 32 帧，必须含换腿（passing）关键帧 |
| 顶部悬挂 | 20 帧，摆动更慢、抓点固定 |
| 身上黑影 | 代码里的地面阴影高斯模糊吃进脚底；下移并减弱，不改角色线稿 |

## 1. 气泡

1. `create_window(..., transparent=True, shadow=False)`。
2. 气泡 HWND 使用 `DWMWCP_DONOTROUND`，避免系统圆角裁掉尖尾。
3. `.shell` 圆角 22px；`.tail` 为旋转 45 度的同色方块，按 `data-tail` 指向咕嘎。

## 2. 动作素材

1. 以现有跑步/悬挂为姿态参考，重绘：
   - 跑步 32 帧：接触、缓冲、换腿、伸展，左右脚交替，鳍反向摆动。
   - 悬挂 20 帧：双鳍抓顶，身体轻摆，体型对齐待机。
2. 保持单轮时长：跑步 `frameMs` 约 54/41，悬挂约 110。
3. 位移仍为每轮 240px。

## 3. 阴影

`build_shadow` 的椭圆下移、透明度降低、模糊减小，使阴影只在脚下地面，不再叠到身体半透明边缘。
