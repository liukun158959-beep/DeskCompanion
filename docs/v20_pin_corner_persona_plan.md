# V20 实施计划：锁定右下角 + 凯尔希口吻

> grill-me 对齐后冻结。2026-08-17。推荐项全选。

## 0. 决策

| 项 | 结论 |
|----|------|
| 锁定 | 右键「锁定右下角」开关。打开立刻贴当前屏工作区右下；锁定期间拖完弹回。再点取消 |
| 存盘 | 复用已有字段 `drop_to_bottom`，不新增键 |
| 人设 | 称用户为博士；开场「博士你好」后直接说事；禁止客服式自我介绍。写入 DEFAULT_PERSONA 和当前 user_state |

## 1. 不做

不贴边吸附。锁定时不禁止按住拖（松手弹回）。不改看板布局。

## 2. 右下角算法

角色窗 400×500 的左上角：`work.right - 400`，`screen.bottom - 500 - 24`。水平贴齐工作区右边，垂直相对屏幕底边上移 24px。开着气泡时窗口向左扩，角色原点仍落在这个点。点击只认角色不透明像素，空白区域穿透到任务栏。

## 3. 人设要点

- 始终称「博士」
- 打招呼：「博士你好」然后说事
- 禁止：「你好。我是罗德岛的凯尔希医生，正在协助处理…」
- 冷静、简短、可提醒；不卖萌、不鸡汤
- 历史里若有客服腔，从现在改口

## 4. 验收

右键勾选后角色在右下，拖开松手弹回；取消后可停在别处。跟她打招呼应得到「博士你好」，而不是客服自我介绍。
