# V10 实施计划：左右松手直接 cling

> grill-me 对齐后冻结。2026-08-14。

## 0. 问题

松手现在是：贴边 → 一律播落地压缩 → 播完才 idle/cling。

落地是脚踩地的 squash，只适合底边。左右边会先站着弹一下，再切扒边，姿态和贴边 bbox 各跳一次。

不要新画过渡帧。Cling 本身就是「挂到这条边上」。

## 1. 决策

| 边 | 松手 |
|----|------|
| 底 | 贴边 → 落地压缩一遍 → idle |
| 左 / 右 | 贴边 → 直接 cling，不播落地 |
| 顶 | 贴边 → 直接 idle，不播落地 |

## 2. 改动

`pet.py` `_on_release`：仅 `edge == "bottom"` 时 `drag_land()`。其它边沿用 `_snap_to_edge` 里已经切好的 idle/cling。
