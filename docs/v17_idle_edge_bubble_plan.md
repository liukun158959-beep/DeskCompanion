# V17 实施计划：待机恢复、显示器贴边、气泡不拖慢、跳跃不横移、去白底

> 用户否决冻帧待机，并补充贴边/跳跃/气泡。2026-08-15 对齐后冻结。

## 0. 决策

| 项 | 结论 |
|----|------|
| 待机波动 | **素材为主**：12 帧是 4 张同姿势不同画，120ms 整身换像素。代码正弦 bob 已不在。16ms 无条件刷新是次因。恢复播帧，保留「换帧才 blit」 |
| 左右贴边 | `SPI_GETWORKAREA` 只给主屏。改为宠物 HWND 所在显示器的 `GetMonitorInfo.rcWork` |
| 打开气泡变慢 | 每帧 `place_form` + 刷透明 + 偶发 JS。跟随只 `move_form`，不改尺寸、不刷透明、不跑 JS |
| 跳跃右移 | 预览把 cling 的 `sx` clamp 进屏内；跳跃每帧又用 `left/right-sw` 夹 X。跳跃只改 Y，预览不夹 X |
| 气泡白底 | WebView2 透明不稳。窗体/页面底用品红做色键抠掉矩形；卡片和输入条用奶白，禁止再写 `#fff`。不做生图 |

## 1. 不做

不冻待机、不重绘 webp、不把气泡改成整窗 PIL（色键仍白再单独立项）。
