# V9 设计计划：原动作表非像素风统一重绘

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 重绘范围 | 只重绘原 8×9 动作表；cling、drag-lift、drag-land 暂不重绘 |
| 视觉标准 | 提取现有 cling/drag 的共同画风：平滑粗线、柔和赛璐璐阴影、完整衣服体积 |
| 角色身份 | 保留原图圆润头身比、脸型、发型、企鹅帽、银回形针、鳍和黄色蹼足 |
| 动作 | 原帧姿态、方向、表情与帧序不变 |
| 推进方式 | 先做 3 个代表帧同屏样稿，确认角色母型后再扩展整表 |

## 1. 三帧试制

1. 待机正面：验证脸型、头身比、帽子和基础配色。
2. 跑动侧面：验证侧脸、身体旋转、鳍与脚的体积。
3. 失败坐下：验证压缩姿态、闭眼表情和衣服褶皱。

三帧使用相同的线宽、色板、眼睛画法、阴影方向和配件尺寸，并与现有 cling/drag 同屏检查。

## 2. 画风约束

1. 禁止像素描边、锯齿和锐化光晕。
2. 在高分辨率画布上直接绘制平滑曲线，不对低清帧做放大锐化。
3. 深灰企鹅服、暖棕头发、奶白肚皮和黄色蹼足使用固定色板。
4. 银色回形针的形状与大小固定；发夹始终位于角色左侧。
5. 不因动作改变眼距、头宽、帽眼位置或嘴喙比例。

## 3. 试制通过后的整表流程

1. 将每个原帧作为姿态参考，按冻结母型逐帧重绘。
2. 每行完成后检查相邻帧轮廓漂移和锚点。
3. 最终导出每帧 384×416 的 RGBA 无损 WebP，仍保持 8×9 布局。
4. 不修改运行时代码、动作帧数、帧速和行为逻辑。

## 4. 本轮不做

在三帧样稿确认前不批量重绘整表，不改 cling/drag，不再使用“低清放大+锐化”冒充高清重绘。
