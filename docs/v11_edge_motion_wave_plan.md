# V11 实施计划：四边动作、位移曲线与六帧挥手

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| cling 修复 | 身体跨过边界时距离记为 0，不再使用坐标绝对值 |
| 挥手 | 只挥画面左侧的鳍，重画为 6 帧 |
| 跑步位移 | 每轮水平移动 120px，左右方向分别取正负 |
| 跳跃位移 | 垂直轨迹最高 52px，结束回到原高度 |
| 顶部动作 | 双鳍抓住顶部边缘，身体在屏内悬垂，脚轻晃 |
| 跑步缺陷 | 单独重画向右跑第 3 帧，禁止黄色脚穿过腹部 |

## 1. 边缘吸附

1. 计算身体矩形到边界线的区间距离：
   - 边界穿过身体矩形时距离为 0；
   - 身体完全在边界一侧时取最近端点距离。
2. 左、右、顶、底四边均使用 48px 阈值；超过阈值保持 `free`。
3. 左右进入对应 cling，顶部进入 `cling-top`，底边播放落地。

## 2. 六帧挥手

1. 画面左侧鳍保持唯一运动肢体。
2. 六帧顺序：放下、半抬、抬高、停顿、半落、放下。
3. 身体、帽子、另一侧鳍、脚底锚点保持稳定。
4. 播放速度 120ms/帧，总时长约 720ms。

## 3. 动作位移

1. 向右跑 8 帧累计 +120px；向左跑累计 -120px。
2. 通用跑动 6 帧按向右累计 +120px。
3. 跳跃 5 帧纵向偏移：`0, -28, -52, -28, 0`。
4. 位移按当前缩放倍率缩放，并限制在工作区内。
5. 动作预览开始前切换到 `free`，避免在 cling 裁切位置原地播放。

## 4. 顶部资源

- 文件：`skins/guga/cling-top.webp`
- 6 帧，每帧 384×416，总尺寸 2304×416。
- 双鳍固定抓住画面顶边，身体和黄色蹼足位于屏内。
- 循环包含轻微左右摆、眨眼和回中；抓点不漂移。

## 5. 验收

1. 光标拖到左右边缘松手时稳定进入 cling。
2. 顶边 48px 内松手进入顶部悬挂，中间松手仍保持原位。
3. 挥手六帧只动画面左鳍，无手臂瞬移。
4. 跑步一轮移动 120px；跳跃达到 52px 后回原高度。
5. 向右跑第 3 帧腿脚轮廓完整，不穿过腹部。

## 6. 不做

不启用自动巡游，不让跑步持续到边缘，不改变用户已确认的中央释放策略。
