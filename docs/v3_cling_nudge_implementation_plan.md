# V3 实施计划：小气泡开关、贴边、缩放、到点纸条

> grill-me 对齐后冻结。2026-08-14。推荐项全选。
> 参考：OpenPets 短句气泡 + 工作区漫游；Desktop-pet 分档缩放。不爬第三方窗口。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 点角色 | 对话卡开着则关，关着则开 |
| 平时 | 角色头顶一行奶油纸条，不盖身体；点纸条或点角色都展开对话卡 |
| 对话卡 | 240×320，按精灵身体矩形侧面留缝，禁止和身体重叠 |
| 主动搭话 | 12–18 分钟一条模板（快开会 / 过期待办 / 时段问候），不调模型、不建习惯引擎 |
| 静音 | 托盘「主动搭话」开关 |
| 贴边 | 工作区四边走和坐；允许半身探出。不爬其它应用窗 |
| 缩放 | 滚轮三档 1x / 1.5x / 2x，右键同样；写入 user_state.json |
| 记忆 | `memory/chat.jsonl`，用户主动对话才写入 |
| 不做 | 每日启动跑 Atlas 推荐、Electron、Shimeji 爬窗、无级缩放、品红扣图 |

## 1. 现有代码

分层窗、贴边走、三档缩放、托盘开关、模板 `nudge.py`、头顶纸条已经在树上。本波补齐缺口。

## 2. 缺口与改法

1. 关对话卡：以 Win32 `IsWindowVisible` 为准；`SetWindowPos` 禁止再带 `SWP_SHOWWINDOW` 把已隐藏的卡拉出来。
2. 对话卡按精灵身体矩形定位，不要按整块分层窗（含 padding / 纸条带）。
3. 滚轮不再要求 Ctrl。
4. 贴边允许约四成身体探出工作区；沿边走时同样探出。
5. 无近日程/过期待办时用时钟问候；飞书失败把错误写在纸条上，不编造。
6. 删启动时的每日 Atlas 推荐和 `last_daily_date`。
