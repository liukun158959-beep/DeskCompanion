# V19 实施计划：更小角色、气泡不挤、对话动作、凯尔希人设、表情残影

> grill-me 对齐后冻结。2026-08-17。推荐项全选。

## 0. 决策

| 项 | 结论 |
|----|------|
| 尺寸 | 角色窗改为 400×500。滚轮仍是 1 / 1.5 / 2，当前 1x 会明显变小 |
| 气泡 | 关掉时角色独占窗口；点开时窗口向左扩 320px，角色屏幕坐标不变、不裁切 |
| 对话动作 | 思考/回复中循环播「疑问」；结束「叹气」；失败「烦躁」；然后回待机 |
| 人设 | 按 PRTS/干员档案写成凯尔希，写入 `DEFAULT_PERSONA` 和当前 `user_state.json` |
| 残影 | 表情播完把参数打回默认再回 Idle；画布每帧清空。不改模型贴图 |

## 1. 不做

不改看板壳。不新增缩放档位。不开气泡时不播动作。不把气泡叠在角色身上。

## 2. 气泡布局

- 关：窗口 400×500，画布铺满
- 开：窗口变为 720×500，`x -= 320`，画布仍绝对定位在右侧 400px
- 存盘坐标永远是角色窗左上角（开气泡时把 `x+320` 写回去）

## 3. 动作

- `set_busy(true)`：播 Talk，忙完之前 Talk 结束就再播
- `set_busy(false)` / 表情结束：参数复位 + Idle
- `review` / `fail` 仍走 Done / Fail

## 4. 验收

启动后角色比现在小；点开气泡凯尔希不挪、不被裁；发一句对话她有疑问动作；看板人设是凯尔希；表情结束后回到待机，不留下上一动作的姿势。
