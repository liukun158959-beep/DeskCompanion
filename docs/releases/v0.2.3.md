# 知行 ZhiXing v0.2.3 · 视频学习与 Agent 调试

本版把视频学习、模型调用调试和资料管理集中到个人 Agent 工作台，采用经用户确认的彩色手绘主题图。

## 更新亮点

- **视频学习与长视频续读**：读取 Bilibili / YouTube 实际字幕，围绕概念、机制和关系生成学习笔记；按章节分段提炼并保存检查点，中断后复用已完成片段。修复 B 站字幕接口读取、缓存失败覆盖完整字幕、笔记关键词格式差异与连接中断问题。无可用字幕时明确失败，不编造视频内容。
- **飞书视频笔记归档**：连接指定知识库，视频笔记与日报分别管理；支持自动保存、原视频内嵌网页和原生流程图，保留来源与保存回执。
- **Agent 全量调试**：连续点击顶部版本号5次打开窗口，查看实际发往 LLM 的完整消息、工具定义、完整返回及原始 SSE；支持相邻请求比较、JSON 导出、工具与时间线查看和模型辅助解读。记录从新调用开始，默认保存在本机，可暂停。
- **本地文件与知识库**：读取文件和文件夹，将资料添加为附件或加入知识库；飞书文档按实际知识库分组，减少文档增多后的管理负担。
- **轻量工具栏与悬浮附件**：顶部改为文字菜单；Windows 文件选择适配清晰显示，附件窗口可拖动、最小化、取消和关闭，加载期间不阻挡 Agent 对话。
- **连接诊断与任务恢复**：改善飞书应用身份诊断、网络错误分类与连接恢复；模型连接中断最多重试一次，保留已生成草稿并显示失败阶段与完成数量。真实超时和权限问题仍明确停止。
- **功能精简**：移除明日方舟相关游戏业务入口和工具，简化系统提示词；桌宠形象仍可按用户自己的素材配置。

## 下载与升级

下载 `ZhiXing-0.2.3-windows-x64.zip`，完整解压后运行 `ZhiXing.exe`。Windows 10/11 x64 需要 WebView2 Runtime；程序尚未代码签名。升级时关闭旧程序并替换程序目录，用户数据继续保存在 `%LOCALAPPDATA%/DeskCompanion`。ZIP 不包含作者的模型密钥、飞书配置、登录态、聊天记录或私有 Live2D 素材。

飞书功能需单独准备 Node、lark-cli、应用能力与权限；GitHub 集成需 GitHub CLI。知识库检索权重不随包分发，按附带使用说明运行知识库扩展安装脚本并下载模型。可读取的字幕受平台登录状态、字幕供应和网络条件影响；视频分析未读取画面。

随包提供 Python 运行时、固定提交的 Atlas 与显式采样补丁。主题图用于介绍功能，图中的界面是示意图。
