# DeskCompanion v0.2.2 · 版本介绍、更新检查与飞书通知

启动即可了解新能力，更新有入口，发布有通知。

- **启动版本介绍**：适配当前深浅皮肤，图片和说明随包提供，离线可看；首次引导完成后展示，可随时关闭或按 Esc。默认每次启动展示，可勾选每日一次并长期保存偏好；新版本当天仍展示，恢复主窗口不重复弹。
- **设置页检查更新**：手动查看 GitHub 最新正式版本、发布日期和更新说明，直接打开下载页面；失败可重试，不阻碍启动。设置中可重新查看版本介绍。
- **正式版本飞书通知**：GitHub Release 发布后自动向学习交流群发送凯尔希主题图与更新一览卡片。按版本和目标群去重；发送结果不明先核实，允许人工确认后补发，通知失败保留已发布版本。
- **五条大厂技术资讯**：重点关注国内外大厂官方开源项目和技术动向，英文标题带中文翻译；群卡片简述、知识库文档详细说明，图文海报展示重点，资讯记录进入多维表格。
- **独立管理页面**：定时任务、聊天监控台与飞书连接页分离；飞书监控台支持查看执行过程、继续会话和控制是否发送回复。

下载 `DeskCompanion-0.2.2-windows-x64.zip`，完整解压后运行 `DeskCompanion.exe`。先退出旧程序，保留 `%LOCALAPPDATA%/DeskCompanion` 中的配置、聊天、记忆及素材。当前更新需要手动下载和解压。

需要 Windows 10/11 x64 和 WebView2 Runtime。Python 和 Atlas 随包提供；首次使用按引导填写 API 地址、模型名和 Key。公开包不包含 Live2D Cubism Core、凯尔希模型、个人配置和模型权重；素材位置见使用引导。飞书与 MAA 等外部能力需自行准备对应账号、CLI 和授权。当前没有安装器、自动更新器或代码签名。

验证包括后端与前端回归、Rust 测试、TypeScript 检查、正式构建，以及隔离配置下的运行时启动、模型保存/测试、Atlas 流式回复、采样参数、历史和重启恢复。每日一次、引导顺序、Esc、手动检查及失败重试都有自动测试。主题图已检查，飞书 Card 2.0 格式已通过平台校验；原生弹窗视觉和正式群卡片的实际交付效果仍以用户审阅为准。
