# V7 实施计划：鼠标拎起与落地动作

> grill-me 对齐后冻结。2026-08-14。

## 0. 决策速查表

| 项 | 选择 |
|----|------|
| 拎取点 | 鼠标拎住头后方的后颈衣领，进入拖动后衣领抓点固定跟随光标 |
| 拖动姿态 | 头和身体微微前倾，双鳍与双脚自然下垂并轻晃；半睁眼、嘴角平直，有点无奈 |
| 松手衔接 | 先贴到最近工作区边缘，播放一次快速压缩落地，再恢复对应边缘 idle |
| 资源格式 | 独立横条，不写进 8×9 Codex 表；每格 192×208，透明底 |
| 缺失处理 | `drag-lift.webp` 或 `drag-land.webp` 缺失时启动失败并给出明确规格，不用现有动作代替 |

## 1. 动作资源

### 1.1 拎起循环

- 文件：`skins/guga/drag-lift.webp`
- 5 帧，横条尺寸 960×208。
- 后颈衣领抓取锚点固定在每格 `(132, 52)`，不能随帧漂移。
- 企鹅帽保持原本圆弧轮廓，禁止把帽顶拉成长尖角。
- 第 1 帧进入悬挂；第 2、3 帧身体轻微向左右摆；第 4 帧眨眼；第 5 帧回中。
- 角色沿用企鹅连体衣、银色回形针、桨状鳍和黄色蹼足，不画人手。

### 1.2 落地一次性动作

- 文件：`skins/guga/drag-land.webp`
- 6 帧，逻辑横条尺寸 1152×208。
- 顺序：接近、触地、最大压缩、缓冲、回弹、站稳。
- 总时长控制在约 420ms，不做第二次弹跳。
- 企鹅帽保持正常圆弧，不保留后颈抓取褶皱，落地姿态与拎起姿态完全独立。

## 2. 代码改动

1. `skin.py`
   - 增加 `ROW_DRAG_LIFT`、`ROW_DRAG_LAND` 和对应帧间隔。
   - 复用独立横条加载逻辑，严格校验高度、帧宽、帧数和非空帧。
2. `behavior.py`
   - 增加拖动循环状态和落地一次性状态。
   - 落地动作播放完后回到当前边缘 idle。
3. `pet.py`
   - 鼠标移动超过阈值时才正式进入拎起状态，普通点击仍触发挥手。
   - 进入拖动后将后颈衣领固定锚点对齐光标，后续窗口按锚点跟随，不沿用原窗口增量拖动。
   - 松手后贴到最近工作区边缘，播放落地动作；动作结束再恢复 idle。
   - 拖动和落地期间关闭常规正弦上下浮动及地面阴影，避免双重位移。

## 3. 验收

1. 按下但移动未超过 6px 时不切换动作，松手仍视为点击。
2. 超过阈值后后颈衣领立即对齐光标，拖动期间抓取点不漂移；帽顶不变形。
3. 拖动循环中身体和脚轻晃，窗口移动不抖动。
4. 松手后只播放一次落地压缩，再进入最近边缘对应的 idle / cling。
5. 1.0、1.5、2.0 三档缩放都保持抓取点对齐。

## 4. 不做

不添加拖动惯性，不模拟重力下落，不允许缺图时改播 idle，不修改现有点击、右键菜单和滚轮缩放语义。
