# V36：看板自定义顶栏

> 2026-09-03。V35 染系统标题栏失败。Fixes #13。

## 问题

作者拖不动、也看不清顶栏。系统标题栏染成纸色后和内容糊在一起；HTML 顶栏写了 `pywebview-drag`，pywebview 实际认的是 `.pywebview-drag-region`，所以点「看板」那一行拖不走窗口。

## 非目标

- 不开森空岛。不改技能 Markdown。
- 看板不用品红抠图。

## 决策

| 项 | 选择 |
|----|------|
| 壳 | `frameless=True`，去掉系统标题栏 |
| 拖动 | 左侧整块 `.pywebview-drag-region`（标题 + 握把），按钮不在拖动区 |
| 顶栏 | 卡片底 + 腮红描边，握把一条，cursor grab |
| 按钮 | 最小化 / 最大化（再点还原）/ 关闭（仍是隐藏） |
| 改大小 | 无边框仍加 `WS_THICKFRAME`；双击顶栏切换最大化 |
| 外观 | 纸面描深棕边，圆角；关掉 Mica 深色衬底 |

## 验收

Given 打开看板，When 按住顶栏左侧握把或「看板」标题拖，Then 窗口跟着走，点关闭/最小化不会误拖。
Given 深色 Windows，When 看顶栏，Then 是独立一条奶油栏，不是黑条也不是和内容糊成一块。
